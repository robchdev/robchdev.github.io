Privacy leggibile

I tuoi dati restano tuoi

Guanix separa chiaramente ciò che accade sul dispositivo da ciò che passa attraverso un servizio remoto.

  • I modelli locali non inviano dati all’esterno.
  • L’app chiede il tuo consenso prima di usare servizi remoti.
  • Token e chiavi API sono protetti nel Keychain di iOS.
  • Puoi cancellare tutti i dati locali dalle Impostazioni.

Domande frequenti

Prima di iniziare

Serve una connessione internet?

No, se usi un modello GGUF sul dispositivo. Una connessione è necessaria quando scegli un server o un servizio remoto.

Serve un account?

No per i modelli locali. Un token o una chiave sono richiesti soltanto per servizi come Hugging Face o Ollama Cloud.

Dove finiscono i miei dati?

Con i modelli locali restano sul dispositivo. Se scegli un servizio remoto, Guanix ti chiede il consenso prima di inviare le richieste.

Come collego il mio computer?

Avvia un server compatibile sul computer e assicurati che sia sulla stessa rete locale dell’iPhone: Guanix può trovarlo automaticamente.
